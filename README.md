**Velvet Ember Restaurant**

Where Every Meal Becomes a Memory.

Velvet Ember is a modern restaurant website designed to showcase delicious meals, provide an elegant online dining experience, and help customers discover the restaurant's menu and services.

**Features**

Responsive Design — Adapts to desktop, tablet, and mobile screens.

Modern User Interface — Elegant styling with a warm, restaurant-inspired color palette.

Food Showcase — Attractive presentation of meals and restaurant offerings.

Interactive Elements — JavaScript-powered website interactions.

Bootstrap Styling — Uses Bootstrap for responsive layouts and components.

Custom Assets — Includes images, icons, stylesheets, and web fonts.

**🛠️ Technologies Used**

HTML5

CSS3

JavaScript

Bootstrap

jQuery

Swiper.js

Magnific Popup
